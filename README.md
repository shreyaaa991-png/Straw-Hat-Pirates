# Guess the Movie – Picture Challenge

## About the Project

Guess the Movie – Picture Challenge is an interactive quiz game that tests players' knowledge of movies through pictures and visual clues. Players must identify the correct movie within a given time, earning points for every correct answer.

The aim is to create an enjoyable and engaging experience where players can challenge their movie knowledge while competing against the clock.

## Objectives

- Develop an engaging and interactive movie-guessing game.
- Test and improve players' knowledge of movies.
- Create a simple, user-friendly interface.
- Provide an enjoyable gaming experience through timed challenges and scoring.

## Features

- Picture-Based Questions: Identify movies using pictures and visual clues.
- Randomized Questions: Get a different question order each time you play.
- Answer Verification: Check whether the submitted answer is correct.
- Automatic Scoring: Earn points for every correct answer.
- Countdown Timer: Complete each question within the given time.
- Instant Feedback: View feedback after submitting an answer.
- Final Score: See your total score at the end of the game.
- Restart Option: Play another round and try to improve your score.

## Technologies Used

- **HTML5:** Used to build the structure and content of the website.
- **CSS3:** Used for styling, layouts, animations and responsive design.
- **JavaScript:** Used to handle game logic, answer verification, question selection, timer and score calculation.

## Project Structure


The project is organized into separate files and folders to keep the code easy to understand, manage and maintain.
- index.html – The main page where players are introduced to the game.
- game.html – Contains the movie quiz interface and gameplay section.
- results.html – Displays the player's final score and game results.
- style.css – Handles the overall appearance, layout and styling of the website.
- script.js – Controls the game functionality, including answer checking, scoring, timer and question selection.
- images/ – Stores the movie pictures used throughout the quiz.
- assets/ – Contains additional resources such as logos, backgrounds and icons.
- README.md – Provides an overview of the project, its features and instructions for running it.

How to Run the Project

1.Follow these steps to run the game on your computer:
2.Clone or download the project repository.
3.Open the project folder in Visual Studio Code.
4.Make sure all files and image assets are in their respective folders.
5.Open index.html in your web browser.
6.Select Start Game and begin guessing the movies.
